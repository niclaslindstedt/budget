Sweeping accessibility pass: every custom listbox / glyph grid / colour
swatch now supports arrow-key navigation (with Home / End and a roving
tabindex so Tab moves you into the list once and arrow keys move you
inside it), the sheet picker and the desktop Settings sidebar are now
proper ARIA tablists, modals trap focus and return it to the opener on
close, every `<th>` carries `scope="col"`, the auth screen errors
announce via `role="alert"`, the budget shell carries an `<h1>`, and a
batch of small icon buttons (colour swatches, the toast dismiss, the
transfer-anchor toggle) had their hit areas grown to the WCAG 2.2 AA
24×24 minimum without changing their visible glyph.
