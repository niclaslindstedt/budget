Added Dracula, GitHub Dark, and GitHub Light theme presets, adapted from the
popular VS Code themes. The Appearance picker is now split into a Mode row
(Dark / Light / System / Custom) with a Variant row underneath that lists the
themes inside the active mode (e.g. One Dark / Dracula / GitHub Dark for
Dark). The original Dark and Light presets are now labelled One Dark and One
Light to match their upstream theme names.
