The Accounts sheet's two tables (Accounts and Transfers) now use the
same column-header pattern as the budget sheet — an icon is always
visible (tag / bank / wallet for the accounts table; calendar / lines
/ arrows / currency for the transfers table), and the text label is
hidden on mobile to save horizontal space. The accounts table's tag
glyph header sits over the leftmost column so it lines up with the
colored account glyphs below it. On mobile, the transfers table's
date column is narrower and sits tighter against the description to
free up room for the description text, and each transfer row's
`from → to` summary picks up the colored account glyphs from the
accounts list alongside the account names, so source and destination
are recognisable at a glance.
