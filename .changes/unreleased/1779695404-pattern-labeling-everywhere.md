A new "Label similar" item in the row menu opens the pattern modal on any budget row (not just bank-imported history), pre-filled with a date-stripped derivation of the row's description. Saved patterns now auto-apply on manually-typed entries too — type a description, the matching rule's type lands as soon as you blur the cell. Picking a type by hand locks the row out of further auto-relabelling; clearing the type re-engages it. A new "Patterns" tab in Settings lists every saved rule so you can edit or delete one without first finding a matching row.
