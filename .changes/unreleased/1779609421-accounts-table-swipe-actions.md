The **Accounts** table now mirrors the budget sheet's swipe affordance.
On mobile, swipe an account row left to reveal pen / trash / more
actions; on desktop the same strip lives in the right-hand action
column. The fourth column shows the account's imported-transaction
count (clicking the account name still opens the viewer), and the More
(•••) menu groups **View transactions**, **Import bank history** and
**Cut history** together. The new Trash button on each row opens a
confirmation dialog before permanently removing the account along with
its transfers and bank history.
