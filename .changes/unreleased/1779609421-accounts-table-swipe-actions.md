The **Accounts** table now mirrors the budget sheet's swipe affordance.
On mobile, swipe an account row left to reveal pen / trash / more
actions; on desktop the same strip lives in the right-hand action
column. A new history-count column replaces the old eye button — the
number doubles as the view-history trigger, and clicking the account
name now opens the history viewer too. Import and Cut history have
moved into the More (•••) menu, and the new Trash button on each row
opens a confirmation dialog before permanently removing the account
along with its transfers and bank history.
