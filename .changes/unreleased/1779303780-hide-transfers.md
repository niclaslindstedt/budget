Hide inter-account transfers from budget tables. Toggle "Hide transfers between accounts" under Settings → General → Display to suppress synthesized cross-account transactions, history entries marked as transfers (via the new "This is a transfer" checkbox in the entry-edit modal), and any budget row flagged with the new **Mark as transfer** action (under the row's "…" menu). The running balance still accounts for the hidden rows; a small ↔ icon on each affected balance cell reveals the hidden run inline when clicked.
