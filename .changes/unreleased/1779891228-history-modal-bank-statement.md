The account history modal now reads as a plain bank statement: only
the raw bank-statement fields the import carried (date, bank
description, amount, balance) are shown — the type column, resolved
user descriptions, per-month color tinting, and the green/red amount
coloring are gone. User-curated metadata (types, merchant hints,
renames) stays on the budget view, where it belongs.
