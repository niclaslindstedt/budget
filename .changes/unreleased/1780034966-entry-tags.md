Tag your entries. Tags are your own colour-coded labels for grouping
entries that cut across categories — "Vacation 2026", "Reimbursable",
"Work". Assign one or more when you create an entry, in an entry's edit
modal, or when editing many rows at once, manage them under
Settings → Tags, and search by tag name to pull up everything
labelled the same way. Tags stay out of
the budget table — they only show while editing.
