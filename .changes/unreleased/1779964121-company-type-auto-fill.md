**Auto-fill type from company.** Once you've tagged a company on enough
entries that always carry the same type, the next time you pick that
company on an entry whose type isn't set the type fills in
automatically. The threshold lives in **Settings → General → Auto-fill
type from company** — defaults to 11 occurrences, adjustable from 0
(off) up to 50. Works from the description popover's inline picker and
from every edit modal that has a Company field.
