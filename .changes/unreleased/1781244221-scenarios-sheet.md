type: Added
title: Scenarios sheet
doc: scenarios
---

A new sheet type for what-if modeling against a budget you already track: create scenarios that change amounts — typed in, or as live adjustments (+5 000, ×2, +300 %) that keep tracking the underlying entry when it changes — with an optional sweep across a recurring entry's upcoming occurrences, drop expenses, or add rows without touching the real budget, compare every scenario's projected balance 1 month to 2 years ahead in the Visualize scenarios chart, set monitor dates to see the projected balance on days that matter, and view a scenario's changes as a diff against the unaltered baseline.
